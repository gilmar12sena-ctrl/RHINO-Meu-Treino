# RHINO — Meu Treino

Base inicial do RHINO 2.0, preparada para GitHub e Netlify.

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy no Netlify

O projeto já contém `netlify.toml` com:

- Build: `npm run build`
- Publish: `dist`
- Node: 20
